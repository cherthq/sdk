# CLI beta.7 shared-onboarding test release

Status: published and independently verified from the public npm registry on
October 22, 2026. The `beta` tag points to beta.7; `latest` remains beta.6.
The task branch includes the published beta.6 baseline and the reviewed
shared-onboarding implementation. Artifact source: `bd08177`.

Adds `chert onboard`: existing browser login and project approval, resumable shared
allocation, inbound iMessage verification, hosted demo request and existing-agent
handoff. Optional caller metadata from beta.6 is preserved. No second runtime,
provider credential store or automatic deployment is introduced.

The matching control-plane release, configured pool and qualified worker are
required. Each shared call has a 10-minute pilot ceiling within the project's
100-minute daily allowance. Package installation does not activate a pool or
prove physical call/media success.
