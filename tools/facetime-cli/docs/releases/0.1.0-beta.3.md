Package: [`@trychert/facetime@0.1.0-beta.3`](https://www.npmjs.com/package/@trychert/facetime/v/0.1.0-beta.3), npm tag `beta`.
Before publication: `beta` is `0.1.0-beta.2`; `latest` is `0.1.0-beta.1`.

values from the agent folder's `.env.local` or `.env`. Shell values, explicit

Real FaceTime/Muse calls on this release remain unverified. Prior successful
conversations and automated checks do not establish workshop/fleet readiness.
Only hosts running `chert` need the npm update; FaceTime worker-only Macs do not.
