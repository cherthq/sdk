## Rollout scope

Only update machines that run `chert`. Native FaceTime worker-only Macs require
no changes for this release. No FaceTime backend, worker, OBS, audio route or
hosted Muse deployment is included. Preserve each host's own credentials,
project selection and recovery state. See
[the CLI upgrade instructions](../../CLI_GUIDE.md#update-macs-that-run-the-cli).

The current demo instructions select Chert FaceTime Test
(`5ee3afd6-f248-45a5-9fe8-bf30c4c961e7`), not the previously saved Dev project.
