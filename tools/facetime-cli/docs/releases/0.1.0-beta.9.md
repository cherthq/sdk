## Remaining line-dependent verification

The selected lines must be explicitly qualified and enabled for shared allocation
and the hosted outbound audio/video demo. The matching cloud pool, inbound
verification/acknowledgment transport and demo infrastructure must also be ready.
Package installation does not activate them. A busy or unavailable line preserves
the same saved intent and returns actionable recovery guidance.

Live browser signup through verified acknowledgment, hosted outbound demo media,
terminal cleanup and subsequent customer-agent use remain unverified with this
candidate. Passing isolated mocks does not establish physical call success.
The line/activation owner must coordinate that acceptance after the selected
outbound-ready lines are supplied.

No installed FaceTime worker needs a new binary, package, configuration or restart
for these CLI-only changes. No global CLI was replaced, Mac worker touched, line
enrolled, real call/message/email sent or production state changed by these checks.
