# CLI beta.6 caller identity release receipt

Status: published and independently verified from npm on October 16, 2026
(US Eastern). Both `beta` and `latest` point to this version. Consumer installation
remains separate.

Package: [`@trychert/facetime@0.1.0-beta.6`](https://www.npmjs.com/package/@trychert/facetime/v/0.1.0-beta.6).

Incoming `call.incoming` frames now accept optional `from` containing a phone
number or email, or null for unknown. Legacy frames may omit it. The BYOR prepare
callback and durable journal preserve the first snapshot; conflicting retries
are rejected. Email validation matches the control-plane caller identity contract.
Caller identity is metadata, not verified identity or an authorization credential.
