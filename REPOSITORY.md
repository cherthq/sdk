# Chert SDK

This repository (`cherthq/sdk`, formerly `cherthq/chert-sdk`) contains the Chert language clients and iMessage compatibility
adapters extracted from the branch-local platform work, plus the standalone Node
FaceTime CLI in `tools/facetime-cli`. SDK packages remain private and unpublished
while compatibility and device acceptance continue; the CLI has its own npm
package and release lifecycle.

The native Mac worker and control plane live in `cherthq/chert-facetime`.
Repository publication is separate from package publication and deployment.
